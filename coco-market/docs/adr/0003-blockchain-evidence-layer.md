# ADR 0003 — 블록체인은 증거 계층으로만 쓴다

- 상태: 채택 (2026-10-06)

## 결정
- DB가 원본이다. 체인에는 이용권 계약 서명 해시와 검증된 기여 기록의 해시를 Merkle root로 묶어 기록한다(`anchor.run`).
- 누구나 `anchor.verify`로 특정 이용권·기여가 그 root에 포함됐는지 증명을 받아 검증할 수 있다.
- 사용자 간에 주고받는 토큰, 지갑 보관(커스터디), 가격·수익 정보가 담긴 메타데이터는 만들지 않는다.

## Merkle 규칙
- 리프 해시 = `sha256("00" + 리프)`, 내부 노드 = `sha256("01" + 왼쪽 + 오른쪽)`. 리프와 내부 노드의 해시 영역을 나눠 2차 원상 공격을 막는다.
- 홀수 노드는 위로 그대로 올린다. 리프는 정렬해서 결정적으로 만든다.

## 남은 일
- 실제 체인(EVM L2 또는 허가형 EVM)은 수수료와 규제 해석을 비교해서 정한다. 앵커 컨트랙트는 `bytes32 root`를 이벤트로 남기는 최소 구현으로 하고, 관리 권한은 멀티시그로 두며, 배포 전에 외부 감사를 받는다.
- 원하는 사용자에게 양도 불가 인증서(ERC-5192 계열)를 발급하는 기능은 법무 질의 Q6의 답을 받은 뒤 결정한다.
