# PRD — CO-CO Market Phase 1

## 한 줄 정의
여러 권리자의 IP를 정해진 범위로 빌려 쓰게 하고, 동네 가게 입점·광고 검증 같은 실제 일을 한 사람에게 용역비를 주는 마켓.

## 사용자
| 유형 | 하려는 일 | 핵심 화면 |
|---|---|---|
| 이용자(가게·기업) | 홍보물·굿즈에 쓸 IP 이용권을 산다 | IP 둘러보기 → 상세 → 결제 → 내 이용권(계약서) |
| 권리자 | IP를 등록하고 이용권 상품을 만들어 판다 | 권리자 스튜디오(등록 위저드, 상품, 심사 요청, 판매 현황) |
| 공동권리자 | 지분대로 정산받는다 | 동의(전자서명), 정산 |
| 기여자 | 퀘스트를 수행하고 용역비를 받는다 | 퀘스트 보드(스탬프판), 제출, 정산·출금 |
| 가맹점 | 입점하고 IP를 홍보에 쓴다 | 가맹점 입점, 가입비 결제 |
| 운영(심사·재무·컴플라이언스) | 심사, 검증, 출금 승인, 분쟁, 법적 게이트 관리 | 운영 콘솔 |

## Phase 1 범위 (구현됨)
- 회원가입·로그인·모의 본인확인(1인 1계정, 연령 제한)
- 다중 IP 등록(공동권리자 지분·동의), 증빙, 이용권 상품(용도·지역·기간·독점·매체), 심사
- 이용권 구매(독점 충돌 검사, 계약서 생성·서명 해시), 지분 정산 원장
- 퀘스트(등급 제한, 일일 한도, 정원), 기여 검증, 원천징수, 기여 등급
- 가맹점 입점(사업자번호 검증, 온보딩 코드), 가입비 결제, AMBER 영업대행 수수료
- 출금(재무 2인 승인, 분쟁 시 보류), 시산표
- 침해 신고·분쟁 결정, 감사 로그 해시 체인, Merkle 앵커링·검증
- 투명성 대시보드(과거 집계치), Legal Gate Matrix 공개

## 비목표
2차 거래, 토큰 발행, 수익 분배, 확정 수익 표시, 미션 대행, 다단계형 보상(→ `COMPLIANCE_CONFLICTS.md`)

## 성공 기준(초기)
- 활성 IP 수, 이용권 판매 건수, 권리자 정산액
- 검증된 기여 건수, 기여 반려율(부정 지표)
- 분쟁 처리 기간 중앙값
- 원장 불균형 0건, 감사 체인 단절 0건
